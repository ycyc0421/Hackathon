# 复杂版式多表回归样本（Review #38）

本目录保存用于验证复杂单证版式解析与跨单证比对的固定回归材料（含合成原始 PDF、结构化 JSON 输入及 OCR 版面还原输出）。配套解析规则说明见 [`docs/review38-fixes.md`](../../../docs/review38-fixes.md)。

- **运行回归测试**：`python backend/tools/test_review38.py`

测试脚本直接校验三份单证的金额（`GBP 5,049.60`）、包装件数（整票 `55` 箱与行级 `22 / 25 / 8` 箱分层）、毛净重、体积、买卖方主体、单据自身编号（`document_no`）以及 3 个 SKU 商品行中的真实数量冲突（`880 / 880 / 888 PCS`）。

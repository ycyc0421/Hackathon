## 已解决的历史问题

- 创建任务与轮询、上传数量和大小限制已实现，见[数据契约](数据契约.md)。
- 多品名目录、行对齐和逐商品比对已实现；无法可靠对齐会降级。
- 图片和扫描 PDF 已有本地 PaddleOCR 通道，线上发布包含真实探针。
- 前后端统一到一个站点，前端默认同源 API，不再要求独立后端 URL。
- confidence / bbox 缺失时保持 null；未评测返回 NOT_RUN。

以上不代表质量、规则依据或容量已完成验收。建议开发顺序与当前限制见[项目现状与计划](项目现状与计划.md)。

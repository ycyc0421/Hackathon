## 1. 业务背景与痛点

在跨境贸易与国际物流业务中，同一票货物往往涉及**商业发票（Commercial Invoice）**、**装箱单（Packing List）**、**提单（Bill of Lading）**、**报关单**及各类电子报文等多份单证。由于各单证由不同参与方（出口商、货代、承运人）生成，格式、版式、计量单位与语种各异：

- 人工逐份核对件数、毛净重、体积、金额、品名与 HS 编码耗时费力，且极易漏检；
- 单证之间一旦出现数据不一致或遗漏目的国所需的随附证明，极易在清关环节引发查验滞港、退运或行政处罚。

## 2. 赛题核心能力要求

| 能力维度 | 赛题要求 | 本项目落地实现 |
|---|---|---|
| **多格式单证解析** | 解析 PDF、图片、EDI 等格式单证，提取 HS 编码、数量、重量、金额等关键字段 | 支持文本层 PDF 直读、图片与扫描 PDF 的本地 `PaddleOCR-VL-1.6` 识别、结构化贸易 JSON 输入，以及 `.edi` 原件预览与兼容演示 |
| **多单证交叉比对** | 交叉比对同一票货物的多份单证，准确标记不一致与缺失项 | 支持整票字段与多商品行（按货号/品名自动对齐）分层比对，严格区分一致、不一致、部分缺失、未校验与单来源字段，并支持同屏原件对照与人工修正重算 |
| **目的国合规提示** | 依据目的国规则提示证书缺失或编码归类风险，并输出结构化报告 | 内置美、德、荷、法、英五国规则与官方法规来源动态监测，区分规则命中与模型建议，支持导出自包含 HTML 报告与完整归档 JSON |

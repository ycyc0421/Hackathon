# 演示与验证指南

本文档提供线上体验与本地回归的标准操作步骤、推荐测试样本及预期核对清单。

---

## 1. 模式选择

- **真实后端模式（默认，或访问 [`?mock=0`](https://hackathon.ychome.net/?mock=0)）**：单证上传至服务器，经真实解析流水线（文本层 PDF 直读 / PaddleOCR-VL-1.6）与比对引擎处理。
- **示例演示模式（访问 [`?mock=1`](https://hackathon.ychome.net/?mock=1)）**：加载内置契约样例，用于快速浏览多场景界面交互，不向后端发送文件。顶栏下方常驻提示条标明当前模式。

---

## 2. 推荐演示样本与预期结果

测试样本均位于 [`backend/samples/`](../backend/samples/)。每次检查请上传同一子目录下、属于同一票货物的一组文件：

| 样本目录 | 目的国 | 验证重点 | 预期核对结果 |
|---|---|---|---|
| `01_us_consistent`（PDF） | `US` | 基础字段一致 | 任务 `COMPLETED`，不一致计数为 0；单来源或未校验字段如实展示，不宣称整票合规通过 |
| `02_de_conflict`（PDF） | `DE` | 跨文件数值差异 | 检出非零不一致项，差异页与报告页均可追溯各来源文件的原始读数与归一值 |
| `04_de_multiitem`（PDF） | `DE` | 多商品行分组比对 | 按商品货号分组展示，行序不同不影响同名字段跨文件对齐 |
| `06`、`07` 号样本（PDF） | `DE` | 缺行与对齐降级 | 缺少对应行或无法可靠对齐时标记为 `MISSING_IN_SOME` 或 `NOT_CHECKED`，不误判为一致 |
| `11_de_multiitem_mixed`（PNG） | `DE` | 多品名图片 OCR | 三张图片全部抽取成功，识别出 4 个商品行、检出品名颜色差异，并保留 OCR 校正证据与告警 |
| `11` 号扫描件（无文本层 PDF） | `DE` | 扫描 PDF 渲染 + OCR | 本地预检提示「疑似扫描件」，服务端完成逐页渲染与 OCR 抽取，商品与冲突完整检出 |

> 09–11 号挑战集样本的逐字段预期说明见 [挑战集金标预期](../backend/samples/challenge/金标预期.md)。

## 3. 页面核对清单

1. **首页（`/`）**：首屏展示入口与三步流程；向下滚动可查看核心能力说明与并排比对示意；在 `?mock=1` 模式下底部展示分组预设场景卡片，点击即可直达演示。
2. **上传页（`/upload`）**：
   - 校验文件格式、单文件大小（≤20MB）、总份数（≤10 份）及同名文件拦截。
   - 选择无文本层 PDF 时显示「⚠ 疑似扫描件」非阻塞提示。
   - 提交后在同一任务卡片内展示阶段进度、逐文件状态（排队中 → 解析中 → 已抽取 / 处理失败）与「已处理 x / n 份文件」计数；完成后右上角主按钮描边引导跳转差异页。
3. **差异页（`/diff`）**：
   - 支持「需关注 / 不一致 / 未校验 / 全部」筛选，多商品任务按商品分组展示。
   - 每张比对卡片支持「表格 | 对照」双视图切换；点击「查看原文」在页面右侧滑出原件预览抽屉（PDF 自动跳页）。
4. **报告页（`/report`）**：
   - 顶部结论条按结果严重度着色，汇总计数与下方条目严格一致；文件清单展示中文单证类型与各文件自身编号（`document_no`）。
   - 规则提示拆分为「依据规则的提示」与「未经规则校验的提示」两张卡片。
   - 真实任务终态下支持**导出自包含 HTML 报告**、**导出归档 JSON**，以及对已有抽取值提交**人工修正并重算**。
5. **系统评测页（`/eval`）**：
   - 独立展示固定数据集上的字段抽取与冲突检出实测指标（精确率、召回率、F1 与 TP/FP/FN 计数）、错误分类及复现指纹；支持按通道切换历史批次。

## 4. 本地自动化验证命令

在仓库根目录执行（需 Node.js 20+ 与已配置好依赖的 Python 3.12 环境）：

```sh
# 1. 数据契约与前端测试、构建
npm ci
npm --prefix web ci
npm run validate
node --test tests/*.test.mjs
npm --prefix web run build

# 2. 后端单元与接口契约回归（自动隔离数据库并关闭外部模型）
python -m pytest

# 3. 数据层与部署回退回归
python -m unittest discover -s data -p 'test_*.py' -v
python -m unittest discover -s deploy -p 'test_*.py' -v
```

如需验证本地真实 OCR 通道（需已安装 OCR 依赖或启动本地 VL 服务）：

```sh
export PADDLE_OCR_ENABLED=1
python backend/tools/run_ocr_probe.py 11_de_multiitem_mixed
```

如需对合成样例输出目录执行独立 Schema 与引用自洽性校验：

```sh
python backend/tools/selftest.py
node backend/tools/validate_outputs.mjs backend/.out
```

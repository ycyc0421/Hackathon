# 项目现状与开发计划

更新于 2026-10-12。线上基线为 `76ffb55`，本分支新增的逐文件进度待合并部署。

## 已有能力

- `https://hackathon.ychome.net` 提供同源页面与 API；默认示例模式，`?mock=0` 使用真实后端。
- 文本层 PDF、图片和扫描 PDF 抽取，整票及多商品比对，原始读数追溯和演示规则提示。
- OCR 对不可靠表格显式失败；有限 O/0 校正保留原读数与人工核对提示。
- 上传、差异、报告、评测四页；真实评测尚未运行，规则未经正式核实。
- 任务与结果持久化到 SQLite，旧 JSON 自动迁入并保留兼容导出；重启中断的任务标记为失败，需重新上传。
- 整站版本发布、失败回退、契约校验、样例回归和 OCR 公网探针。

## 本分支新增

- 上传到终态共用同一任务卡，持续显示阶段和逐文件状态。
- 后端每份文件开始、结束各发布一次 documents 快照；前端补齐排队项并递增已处理计数。
- VITE_PROXY_API 支持开发代理，生产继续使用同源 /api/v1。

## 开发流程

分支实现 → 契约及模块回归 → PR 审查 → 合并 → main CI → 自动部署 → 公网与浏览器验收。

接口变更先同步 Schema；数据库升级先验证备份、迁移和回退。部署配置与操作见[部署运维](部署运维.md)。

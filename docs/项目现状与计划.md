# 系统现状与演进规划

更新日期：2026-10-14 · 在线服务：[https://hackathon.ychome.net](https://hackathon.ychome.net)

---

## 一、已上线核心能力

1. **同源整站服务**：`https://hackathon.ychome.net` 统一承载 Vue 3 前端与 FastAPI 后端 API（`/api/v1`），默认连接真实后端，支持通过 `?mock=1` 切换至示例演示模式。
2. **多源单证解析与证据保留**：
   - 支持文本层 PDF 直读，以及图片、无文本层扫描 PDF 的 OCR 识别（生产环境搭载 **PaddleOCR-VL-1.6** 版面理解与识别引擎）。
   - 保留原始读数（`raw_value`）、原文片段（`raw_text`）及页码定位；对不可靠的多表或缺失关键列显式标记解析失败，对数字 `0` 与字母 `O` 的受控单位校正如实标记 `LOW_CONFIDENCE` 与人工核对提示。
3. **单票多品名对齐与交叉比对**：
   - 支持整票字段与多商品行（`items[]`）分层抽取与比对，优先按商品货号、其次按规范化品名描述跨文件对齐，不受行序变化影响。
   - 严格区分 `MATCH`（一致）、`CONFLICT`（不一致）、`MISSING_IN_SOME`（部分缺失）、`NOT_CHECKED`（未校验）、`UNRECOGNIZED`（无法比对）与 `SINGLE_SOURCE`（仅一份文件提供）。
4. **目的国合规提示与来源监测**：
   - 内置美（US）、德（DE）、荷（NL）、法（FR）、英（GB）五国演示规则，区分「依据规则的提示」与「未经规则校验的提示」。
   - 部署独立定时任务监测欧盟委员会、EUR-Lex、FDA、GOV.UK 等官方法规来源更新，记录 SHA-256 快照与待复核变更。
5. **全流程工作台、原件预览与报告导出**：
   - 涵盖首页、上传、差异、报告、评测五个完整页面，支持深浅色双主题切换与纸张层叠过渡。
   - 差异页支持表格与并排对照双视图，点击「查看原文」可在右侧抽屉就地预览 PDF（自动跳页）、图片或 EDI/JSON 文本。
   - 报告页基于报告契约 v2 支持导出**自包含 HTML 报告**（可离线查看或打印为 PDF）、导出**完整归档 JSON**，以及对已有抽取值提交**人工修正并触发派生任务重算**。
6. **固定数据集系统评测**：
   - 离线评测工具 `backend/tools/evaluate_dataset.py` 支持对固定数据集（`synthetic-hackathon-v2`，100 票 / 300 份文本 PDF 及扫描变体）按文本通道与 OCR 通道独立跑分。
   - 评测看板展示精确率、召回率、F1 与 TP/FP/FN 原始计数、错误分类及 SHA-256 复现指纹，支持按历史批次切换查验。
7. **SQLite 持久化与自动化发布回退**：
   - 任务、商品关联、修正审计与评测档案均持久化于跨版本共享的 SQLite 与数据目录。
   - GitHub Actions 流水线在通过契约、前端、后端、数据层与部署回归后自动发布上线，执行公网真实 OCR 探针，验证失败时自动回退至上一可用版本。

## 二、后续演进方向

| 方向 | 演进内容 | 说明 |
|---|---|---|
| **EDIFACT 报文解析器接入** | 接入标准 `UN/EDIFACT INVOIC / DESADV` 后端解析器，打通 EDI 与 PDF/图片混合比对的真实服务端链路 | 前端 `.edi` 上传、原件纯文本预览及合成场景演示已就绪（见 [EDI 兼容样例说明](fixtures/edi/README.md)） |
| **单证版式与字段扩展** | 扩展报关单、原产地证、保险单等单证类型的必需字段规则表，补充地址与贸易条款比对 | 当前最小字段规则表聚焦商业发票、装箱单与提单核心 11 项字段 |
| **目的国法规核实与扩充** | 对官方来源监测捕获的法规正文完成人工条款核实，扩充更多贸易国别与 HS 章节细则 | 未经人工核实的规则始终保持 `UNVERIFIED` 提示，不自动转为强制结论 |
| **多模态评测集扩充** | 在现有合成评测集基础上，扩充多版式、多语种与复杂扫描件的授权基准样本 | 持续通过 `evaluate_dataset.py` 沉淀可复现的分通道评测档案 |

## 契约的两种形式

`数据契约.md` 与 `schema/` 描述同一套约定，内容必须一致。改动时两者同步修改，顺序为：

1. 修改 `schema/` 下的 JSON Schema
2. 执行 `npm run validate`，确认示例数据仍然合法
3. 同步修改 `数据契约.md`

`schema/` 为准。`数据契约.md` 是它的可读版本。

## 适用范围

本目录下的契约文档只覆盖前端需要对接的部分：前端展示所需的数据格式，以及前端向后端提出的接口要求。抽取算法、数据库设计、合规规则内容不在范围内。

契约由前端侧起草，需数据侧与后端侧确认后冻结。`待确认事项.md` 只列与该两侧相关的事项。

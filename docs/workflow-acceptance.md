# 报告导出与人工修正工作流验收指南

本文档说明人工修正重算、结构化报告导出与结构化贸易 JSON 输入的自动化验收脚本与浏览器核对步骤。

---

## 1. 自动化接口验收脚本

在仓库根目录执行：

```sh
python backend/tools/accept_workflow.py
```

该脚本使用隔离的临时 SQLite 数据库与上传目录，自动验证以下完整闭环（输出写入忽略提交的 `backend/.out/workflow-acceptance/`）：

1. 上传两份初始件数均为 `120 CARTONS` 的结构化单证，确认初始比对状态为 `MATCH`。
2. 调用 `POST /api/v1/checks/{id}/corrections` 将其中一份单证的件数修正为 `121 CARTONS`，验证派生任务自动重算并检出 `1` 处件数 `CONFLICT`。
3. 验证原任务结果与原始读数（`raw_value`）保持不变，修正后的字段带 `LOW_CONFIDENCE` 标记，且修正审计链完整记录修改前后的值与原因。
4. 验证同 `request_id` 幂等重试、过期 `source_hash` 的 `409` 冲突拦截、结构化报告（`view=content`）与完整归档（`view=archive`）导出，以及数据库重连后的状态保持。

---

## 2. 浏览器交互核对步骤

在真实后端模式（`?mock=0`）下，可按以下清单完成端到端交互核对：

1. **创建检查**：上传同一票货物的多份单证（可使用 `backend/samples/` 下的 PDF/PNG 或 `backend/.out/workflow-acceptance/` 生成的 `invoice.json` / `packing.json`）。
2. **提交人工修正**：进入「报告」页底部的「报告导出与人工修正」卡片，选择任一已抽取字段，填入新值与修改原因后点击「保存修正并重算」。
3. **核对派生结果**：确认页面自动切换至派生任务，顶部结论与问题列表实时反映修正后的比对结果，且刷新页面后仍可通过 URL 中的 `task` 参数恢复该任务。
4. **导出与打印报告**：
   - 点击「导出 HTML 报告」，在浏览器中打开下载的 `.html` 文件，核对检查概要、文件清单、比对条目、风险提示、人工修正记录与版本来源追溯，并通过浏览器「打印 → 另存为 PDF」验证打印排版。
   - 点击「导出归档 JSON」，核对完整抽取结构与修正前后审计记录。
5. **模式边界**：切换至示例数据模式（`?mock=1`），确认导出与修正面板显示模式限制说明，不发送真实服务端请求。
